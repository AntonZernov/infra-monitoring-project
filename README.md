## Скрипт мониторинга API:

scripts/check\_api.sh

Использование: 

Сделать исполняемым

```bash
chmod +x check_api.sh
```

Передать проверяемый ресурс в качестве аргумента

```bash
./check_api.sh https://github.com
```

## Docker Compose для стека мониторинга

Запуск

```bash
docker compose up -d
```

Проверка, что сервис мониторинга запустился на 8080 порту

```bash

```

Проверка проксирования с 80 на 8080 порт

```bash
curl http://localhost:80
```

## Этап 6. Инструкция по SSH деплою на удалённый сервер

### 1. Генерация SSH-ключей
На своем ПК в терминале выполнить команду:
```bash
ssh-keygen -t ed25519 -C "infra-monitoring"
```
Соглашаться на все вопросы. Будет создан ключ в пользовательской папке без пароля.

### 2. Копирование публичного ключа на сервер
Чтобы связать свой ПК и сервер, необходимо отправить публичный ключ (заменить `user` на имя пользователя, а `server_ip` — на IP-адрес сервера):
```bash
ssh-copy-id user@server_ip
```

### 3. Передача и деплой проекта
Для быстрой передачи всех файлов проекта одной командой упакуем их в архив, передадим через SSH и сразу распакуем на сервере.

```bash
tar -czf - . | ssh user@server_ip "mkdir -p ~/app && tar -xzf - -C ~/app && cd ~/app && docker-compose up -d"
```

1. `tar -czf - .` - создать новый архив, сжать (файл с дефисом - в оперативную память), точка - текущую папку
2. `| ssh user@server_ip` - отправить архив на удаленный сервер.
3. `"mkdir -p ~/app ..."` - создать папку `app`, если папка существует, то использовать ее 
4. `tar -xzf - -C ~/app` - по пайплайну распаковать в нее архив, если предыдущий опретор (создать папку) выполнился успешно
5. `cd ~/app && docker-compose up -d` - перейти в папку `app` запустить контейнеры в detouch режиме (в отрыве от сессии терминала)
