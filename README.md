# infra-monitoring-project

**Скрипт мониторинга API:** scripts/check_api.sh

Использование: 

сделать исполняемым

```bash
chmod +x check_api.sh
```

Передать проверяемый ресурс в качестве аргумента

```bash
./check_api.sh https://github.com
```

**Скрипт анализа логов API:** scripts/analyze_logs.sh

Использование: 

сделать исполняемым

```bash
chmod +x analyze_logs.sh
```

Запуск

```bash
./analyze_logs.sh
```
